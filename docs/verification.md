# Joybit verification — updated 2026-11-05

## Five-game iOS simulator build and catalog — 2026-11-05

Expo prebuild and CocoaPods installation completed with Xcode 26.6. The current five-game app built for the iPhone 17 / iOS 26.4 simulator using `CODE_SIGNING_ALLOWED=NO` (`** BUILD SUCCEEDED **`), then `simctl install` and `simctl launch` succeeded. With temporary placeholder Supabase public values in the Metro process, the guest catalog rendered all nine entries. The five new entries appeared in the scrolling grid with their titles and artwork; [middle](design/video-games/ios-catalog-middle.png) and [bottom](design/video-games/ios-catalog-bottom.png) simulator screenshots record the layout. Tapping Hex Garden as a guest opened the email sign-in screen, and its back control returned to the catalog.

The owner subsequently supplied the project's public Supabase URL and publishable key. They were stored only in the ignored local `.env.local`, and Expo prebuild regenerated the native project with these values. The iPhone 17 simulator build then succeeded with code signing enabled, `codesign --verify --deep --strict` passed, and the app installed and displayed the login page. This simulator signature is ad hoc (`TeamIdentifier=not set`), so it is not a developer-signed device build. The project's `/auth/v1/settings` endpoint returned HTTP 200 through the machine's configured ClashX proxy. No account credentials were supplied or entered during this check.

The owner then signed in on the simulator with an existing account. Hex Garden, Lane Glow, Little Corner Kitchen, and Hidden Nook each completed level 1 in the native WebView host, and the next-level toolbar control enabled. Hex Garden level 2 loaded after selecting it. Lane Glow and the kitchen and hidden-object games advanced their timers. Returning to the catalog and restarting the app kept the session, so the initial SecureStore persistence path worked in this ad-hoc-signed simulator build. The catalog displayed a favorites-sync retry banner; cloud favorites remain unverified.

Star Trail opened but its launch initially left the orb at the start. The simulator exposed `ReferenceError: Can't find variable: bytecode` when its timer fired. The WebView script had embedded a Hermes function via `Function.prototype.toString()`, which produced non-JavaScript bytecode text. The script now contains a plain JavaScript movement function. A regression test simulates Hermes's `toString()` result and confirms the WebView advances; all 55 unit/DOM and 50 UI tests plus typecheck pass after the change. A second simulator playthrough of Star Trail is pending because the Mac locked during reload.

Hex Garden, Star Trail, Lane Glow, Little Corner Kitchen, and Hidden Nook are now bundled offline games in the catalog. Focused tests check levels 1–100 plus higher examples, puzzle routes or feasible orders, pause/retry, and completion messages. `npm test` passed: 54 unit/DOM tests and 50 React Native UI tests across 14 suites. `npm run typecheck` and `git diff --check` passed. `EXPO_NO_TELEMETRY=1 npx expo export --platform ios --output-dir /tmp/joybit-five-games-export` bundled 726 modules successfully. Regression tests cover background auto-pause for Star Trail and Hidden Nook. A local browser preview loaded all five game screens and showed the portrait layouts, including a 390×844 viewport check of the Star Trail controls. The subsequent iOS simulator build and guest catalog inspection are recorded above; these browser checks are not evidence of iOS gameplay.
