# Joybit verification — updated 2026-11-05

## Five-game iOS simulator build and catalog — 2026-11-05

Expo prebuild and CocoaPods installation completed with Xcode 26.6. The current five-game app built for the iPhone 17 / iOS 26.4 simulator using `CODE_SIGNING_ALLOWED=NO` (`** BUILD SUCCEEDED **`), then `simctl install` and `simctl launch` succeeded. With temporary placeholder Supabase public values in the Metro process, the guest catalog rendered all nine entries. The five new entries appeared in the scrolling grid with their titles and artwork; [middle](design/video-games/ios-catalog-middle.png) and [bottom](design/video-games/ios-catalog-bottom.png) simulator screenshots record the layout. Tapping Hex Garden as a guest opened the email sign-in screen, and its back control returned to the catalog.

The owner subsequently supplied the project's public Supabase URL and publishable key. They were stored only in the ignored local `.env.local`, and Expo prebuild regenerated the native project with these values. The iPhone 17 simulator build then succeeded with code signing enabled, `codesign --verify --deep --strict` passed, and the app installed and displayed the login page. This simulator signature is ad hoc (`TeamIdentifier=not set`), so it is not a developer-signed device build. The project's `/auth/v1/settings` endpoint returned HTTP 200 through the machine's configured ClashX proxy. No account credentials were supplied or entered during this check.

The owner then signed in on the simulator with an existing account. Hex Garden, Lane Glow, Little Corner Kitchen, and Hidden Nook each completed level 1 in the native WebView host, and the next-level toolbar control enabled. Hex Garden level 2 loaded after selecting it. Lane Glow and the kitchen and hidden-object games advanced their timers. Returning to the catalog and restarting the app kept the session, so the initial SecureStore persistence path worked in this ad-hoc-signed simulator build. The catalog initially displayed a favorites-sync retry banner; its resolution is recorded below.

The signed-in simulator also opened the embedded native Hexa Landing / Steady Drop main menu. Starting level 1 synchronized the server-side lives display and entered the SwiftUI/SpriteKit game scene with five lives shown. Pause, return to the native menu, and return to Joybit worked; no life was spent during this check. Gameplay completion, life consumption, and rewarded recovery were not exercised.

The favorites retry banner had a confirmed backend cause: a read-only REST request to the configured Supabase project returned HTTP 404 with PostgREST code `PGRST205`, reporting that `public.joybit_favorites` was absent. The owner applied `supabase/migrations/20261102_joybit_favorites.sql` in the shared project's SQL Editor on 2026-11-05. An anonymous REST request then returned HTTP 401 `permission denied`, which is expected because the migration revokes anonymous access. In the signed-in iPhone 17 simulator, retrying favorites sync cleared the banner. A test favorite appeared in My favorites after an app restart; removing it left the list empty after another restart. The test account's original empty favorites state was restored. The Dashboard execution did not record this file in Supabase CLI migration history.

Star Trail opened but its launch initially left the orb at the start. The simulator exposed `ReferenceError: Can't find variable: bytecode` when its timer fired. The WebView script had embedded a Hermes function via `Function.prototype.toString()`, which produced non-JavaScript bytecode text. The script now contains a plain JavaScript movement function. A regression test simulates Hermes's `toString()` result and confirms the WebView advances. After restarting Metro and the simulator, Star Trail level 1 collected its star, reached the exit, displayed completion, and unlocked level 2; the second level loaded. The [simulator completion screenshot](design/video-games/ios-star-trail-complete.png) records the outcome. All 55 unit/DOM and 50 UI tests plus typecheck pass after the change.
