# 五款游戏与参考视频的玩法对齐

参考：[B 站 BV1yr4y1Q714](https://www.bilibili.com/video/BV1yr4y1Q714/)，重点查看约 70–220 秒的五段游戏演示。此前版本的规则和场景过于简化；2026-11-06 的实机反馈要求进一步贴近视频中的实际操作。以下保留原创角色、美术、关卡和品牌。

| 游戏 | 视频里突出的操作 | 本轮调整 |
| --- | --- | --- |
| Hex Garden | 在较大的六角棋盘上放候选拼块，填满一排消除 | 首关起使用更大的棋盘和至少三块候选块；三个轴向的任意完整一排均可消除，发光排只作提示。 |
| Star Trail | 在横向平台场景中借助机关让角色经过目标并落入终点车 | 木板覆盖可行路径并能在球移动时点按翻转；球在机关间连续移动，终点改为小车。现阶段仍是可验证的离散路线模拟，尚未采用刚体碰撞。 |
| Lane Glow | 让球持续向前，在更快的赛道上避开障碍和缺口 | 触摸轨道时球会跟随手指连续横移；增加缺口、前进动画和行程条。碰撞仍按最近的三条安全车道判定，以保证生成的 100 关都可验证。 |
| Little Corner Kitchen | 顾客出现、提出菜品需求，在厨台按步骤做菜并出餐 | 顾客队列和订单关联，食材、厨具显示具体图形，盘中即时显示当前食材或成品。配方顺序和限时交付保留。 |
| Hidden Nook | 在不同布置的场景中找清单物品 | 关卡轮换客厅、厨房、温室和书房；第二关起移除物品底座，使它们融入场景。目标、干扰物和提示仍随关卡生成。 |

五款游戏仍采用编号和固定种子生成，1–100 关及更高关卡可复现。后续若要求与参考作品更接近的物理或自由跑酷，应进一步重做 Star Trail 和 Lane Glow 的运动与碰撞模型，并重新验证所有生成关卡。
