# 五款游戏视觉对齐

用户在 iPhone 14 Pro 真机验收后要求：五款游戏的交互画面接近此前概念图，首页首图由当前纯色符号卡替换为对应玩法插画。五张概念图是视觉目标，不作为静态游戏截图铺在可操作棋盘上；关卡、数字、按钮和可点击对象仍由代码实时绘制，保证随机关卡与七语言文字正确变化。

## 设计选择

- 首页卡片使用五张方形、无文字的原创插画，分别突出蜂巢消线、木板接星、霓虹跑道、街角料理、阁楼寻物。标题和收藏按钮继续由 React Native 绘制。
- 游戏内保留现有关卡规则与触控命中区域；用 CSS/SVG 提升场景层次、颜色、物件辨识度和反馈。静态概念图不能承载随机生成的棋盘、障碍、订单或目标。
- 以 iPhone 14 Pro / iPhone 17 竖屏为主要检验尺寸，兼容更窄的 360px WebView。重要按钮须可见或能自然滚动到达，且不能被安全区域挡住。

## 视觉系统

圆角、柔和立体阴影、暖色高光和清晰深色文字贯穿五款游戏。每款保留概念图主色：Hex Garden 为奶油白、薄荷绿与紫/珊瑚/金色；Star Trail 为天空蓝、木色和金色；Lane Glow 为蓝紫暮色、青色霓虹和珊瑚障碍；Little Corner Kitchen 为珊瑚红、木色与鲜绿；Hidden Nook 为暖木、薰衣草紫和叶绿。封面主体在约 180×180px 的目录卡片上仍应一眼可辨。

## 技术与来源

封面是 ImageGen 参考仓库 `*-concept.png` 生成的原创方形插画，归一化为 768×768 JPEG，放在 `assets/covers/`。无文字、UI 或第三方视频素材。详细来源和检查状态见 `assets/covers/asset-manifest.json`。游戏内文字、关卡和交互继续使用本地 HTML/CSS/SVG，不从网络加载资源。
