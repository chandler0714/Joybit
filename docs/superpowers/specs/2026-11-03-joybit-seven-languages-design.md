# Joybit 七语言支持设计

## 目标与范围

Joybit 面向中国大陆以外市场，首批支持英语（en）、日语（ja）、韩语（ko）、法语（fr）、西班牙语（es）、俄语（ru）、德语（de）。用户已选择：本轮覆盖 Joybit 平台界面和三款内置小游戏；独立维护的 Hexa Landing 游戏内部暂不扩展语言。Joybit 品牌名和 Hexa Landing 游戏名保持原名。未支持的设备语言回退到英语，不在首批选择列表中显示中文。

## 语言选择

- 首次打开默认“跟随设备”。读取设备首选语言的主语言代码，匹配七种语言；无匹配时使用英语。
- 设置页提供“跟随设备”及七种手动语言选项，名称以各语言自身写法展示。选择立即更新 Joybit 界面与重新打开的小游戏；选择保存在本机，重启仍有效。
- 从手动切回“跟随设备”后重新读取设备语言。iOS 随系统语言变更重启应用；Android 将来恢复到前台时更新设备语言。
- 声明 iOS/Android 支持的语言，以便系统的“单独设置 App 语言”功能识别。Joybit 设置内的手动选择优先于系统选择。

## 文案范围

- 首页、抽屉、收藏、设置、广告占位、游戏卡片标题/游玩人数、返回按钮和无障碍标签全部翻译。
- 邮箱登录、注册、验证码、退出和删除账号界面的 Joybit 文案全部翻译。已知账号错误显示对应语言的用户提示；未知错误显示本地化通用提示，不直接展示未翻译的服务端信息。
- 反应挑战、记忆翻牌、数字拼图的标题、说明、按钮、动态状态、结果、计时/计步和无障碍文本全部翻译；游戏逻辑和离线特性不变。内置 HTML 不加载远程翻译资源，也不接收会话令牌。
- 游玩人数仍只在有真实数据时显示；少于 1000 显示具体数字，以上用向下取整的整数和该语言常用单位。游戏名称在收藏列表与首页一致。
- Hexa Landing 原生游戏内部仍由独立游戏的英/日/韩语言设置控制，其他 Joybit 语言进入时由该游戏自行回退英语。Joybit 自己的原生游戏顶部返回按钮随 Joybit 语言变化。

## 方案比较

**选择：设备默认 + Joybit 设置内手动切换。** 使用 Expo 的设备语言能力和支持语言声明；平台文案集中管理，页面通过共享语言状态即时刷新，内置游戏根据选定语言生成对应的本地 HTML。手动选择存储在本机。

只跟随设备可减少界面，但不符合用户选择的应用内切换。让每个页面单独读取设备语言会造成切换后文案不同步，且难以测试完整性。

## 验收

七种语言都能从设置选择，并覆盖以上 Joybit 界面和三款小游戏；重启后保持手动选择，切回自动时跟随设备，未支持语言回退英语。自动测试检查七语言翻译键完整、语言解析/持久化、主要页面切换、三款游戏动态文案与玩法不退化；iOS 代码可打包。签名版实际触控和系统语言切换在可用构建上复核。
